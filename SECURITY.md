# Security

Please report security problems privately, never in a public issue.

- **With a GitHub account:** [Report a vulnerability](https://github.com/mbdrivechains/freebank-app/security/advisories/new)
  (the repository's Security tab). Only you and the FreeBank team see it.
- **Without one:** in the FreeBank app, Settings, then Help, then **Security problem (private)**, then **Send to
  FreeBank**. It goes to FreeBank's server, where only the FreeBank team reads it. Leave a contact if you'd like a
  reply.

A security problem is anything that could let someone else take coins, read the wallet, its passphrase or the
recovery words, act for a paired phone, run code through the app, or reach your node from outside your computer.

Please give us time to fix a problem before you tell anyone else about it.
