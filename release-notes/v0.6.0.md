# FreeBank app v0.6.0 "Phone link over Nostr"

Your phone now reaches this computer through public Nostr relays, so nobody hosts the link, not even FreeBank's own
server.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **The phone link over Nostr.** Settings › Phone pairs a phone over public Nostr relays (relay.damus.io, nos.lol and
  relay.primal.net by default, editable). Both ends reach out to the relays, which only pass sealed messages along:
  they see two random keys talking and when, never what is said. Everything the phone does stays the same: balance,
  history, Receive, sends within its daily limit, notes, Face ID, approving this computer's payments, and wallets kept
  for a house's shopkeepers.
- **Phones paired before keep the old relay** (app.ecxfreebank.com) until you pair them again. They show "old relay" in
  Settings › Phone. For now you can still pair a new phone over the old relay: it's a link under "Pair a phone". A later
  release retires it.
- **A house can add its own relay** to the list. Nobody has to run one.

## Also

- A resumed snapshot download asks for the rest of the same file only, so a changed file starts over instead of being
  glued to the old part.
- Setup says a link is Tailscale's only when this computer reaches that address over Tailscale. Mobile carriers use some
  of the same addresses.
- Stop and delete during an install can no longer be undone by another stop that ends at the same time.
- "Stop everything and close" now also stops FreeBank's own eCash node and enforcer when "Keep running" is on.
- The log says "stack: stopped" once, not twice.
- The release build retries its downloads.

## Honest limits

- A phone paired over Nostr needs one of its relays to be up. If none answer, the phone says the desktop isn't
  answering.
- Anyone watching these public relays, not just their operators, can see when your phone and this computer talk
  and the sizes (messages are padded to a few sizes), never what is said. The relay operators also see each side's IP
  address, as FreeBank's relay does today.
- The phone page itself still comes from app.ecxfreebank.com.
- Moving a phone to Nostr means pairing it again, and adding Face ID again on it.
- Not yet run on a Mac.
