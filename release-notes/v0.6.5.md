# FreeBank app v0.6.5 "Beta's demo, cleared away"

Beta's demo mode ended in v0.6.2, when newcomers moved to easynet. This release takes out what was left of it, and the
window now comes to the front after the app restarts itself.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **The window comes to the front after a restart the app made itself:** after Update and restart, and after a switch
  of network. On a Mac the new copy used to open behind the other windows. Other starts are as before.
- **Receive on beta no longer offers "Get play money".** It opened FreeBank's beta Telegram bot, which has been
  deleted. On easynet, Receive's Get easynet coins is the way to test coins, as before.
- **The demo's code is gone:** the relay to FreeBank's read-only gateway, Try the demo and Leave demo mode, the DEMO
  watermark, the demo's Home card, and the demo branches of Credit, Settings and setup. None of it had run since
  v0.6.2. The app no longer opens any Telegram link.

## Honest limits

- A computer still in beta's demo mode from before v0.6.2 (none should be: v0.6.2 to v0.6.4 already took it out of
  it) now starts as if it had left it, and setup asks for an eCash node.
- The window's move to the front is up to the system: some Linux desktops show a notice instead.
- Not yet run on a Mac.
