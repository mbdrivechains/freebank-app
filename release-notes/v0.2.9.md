# FreeBank app v0.2.9

Four small things asked for while testing v0.2.8.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Updates with Software Updater, if you want them** (the `.deb`): FreeBank asks once, and Settings › App updates
  offers it later too. Yes adds FreeBank's apt repository to your software sources through your computer's own password
  prompt, trusted only with the key the package installed; after that new versions come with your other updates.
  Nothing is added without your yes. Removing the package (App Center, `apt remove` or `apt purge`) takes the entry
  out again.
- **Remove the app too:** after "Remove FreeBank from this computer", the last screen can remove the app itself: the
  `.deb` through your password prompt (with its entry in your software sources), or the Mac app to the Bin through
  Finder. The AppImage still says which file to delete.
- **Time left while syncing:** the sync screen says "about 12 min left" beside the block counts, from the last few
  minutes' pace. Blocks differ a lot in size, so it's an estimate, and it appears only after a minute.
- **An eCash node on another computer:** Settings says where its user and password come from (the `rpcuser=` and
  `rpcpassword=` lines of that node's config file) and that the data folder stays empty.
