# FreeBank app v0.4.7 "Try the demo any time"

Demo mode is no longer only for your first run, and asking FreeBank's helper takes less typing.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Try the demo from Settings.** If you set FreeBank up with your own eCash node, Settings › Node & connection now has
  **Try the demo**: your node restarts without your eCash node, FreeBank's gateway answering its questions about the
  eCash chain, and Receive has Get play money. Your wallet and data folder stay as they are. **Leave demo mode**, in the
  same place, takes you back.
- **Ask with one key.** The grey example question in the Ask box (it ends with →) becomes your question when you press
  the right arrow; Enter asks it.
- A long link in the helper's answer now wraps inside the box instead of running past its edge.

## Honest limits

- In demo mode there are no deposits or withdrawals, and the eCash tab is hidden.
- In demo mode FreeBank's node stops when the app closes, so Keep running and Keep my phone connected turn off. Turn
  them on again after you leave demo mode.
- Try the demo waits until block bidding is off (on the eCash tab), and needs FreeBank's node v0.2.25 or newer (the
  Node tab updates it). It can't switch a node another program started.
