# FreeBank app v0.6.6 "The .deb updates itself"

On Ubuntu and Debian, the app now updates the way it does elsewhere: **Update and restart** asks for your password,
installs the new version and opens again on it. Until now it could only say that Software Updater would offer the new
version, and Software Updater looks for updates only about once a day.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves. On the
`.deb`, this one still comes through Software Updater (or, with FreeBank's apt repository set up, `sudo apt update &&
sudo apt install freebank`) or the release page; the ones after it come through Update and restart.

## What's new

- **Update and restart on the `.deb`:** the app downloads the new `.deb`, checks it against the release's checksums
  signed with FreeBank's release key (the check the AppImage and the Mac app already make), and installs it through
  your computer's password prompt. The installer receives the checked file itself, writes it to a folder only the
  administrator can change, and checks it again there before apt installs it, so nothing can swap it in between. Then
  FreeBank restarts on the new version. This works whether or not FreeBank's apt repository is set up; Software Updater
  keeps working as before.
- **Without a password prompt on the computer** (no pkexec), with FreeBank's apt repository set up: the update notice
  now says how to update at once, with `sudo apt update && sudo apt install freebank`, instead of waiting for Software
  Updater. Without the repository it points to the new `.deb` on the release page, as before.

## Honest limits

- The password prompt is your desktop's own. If it is closed, nothing changes and the notice stays.
- If Software Updater or another install is running, the update waits for it (up to five minutes) before it gives up.
- Automatic updates ("Update FreeBank by itself") still need the AppImage or the Mac app: the `.deb` needs your
  password each time.
