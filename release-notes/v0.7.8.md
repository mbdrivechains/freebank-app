On easynet, a new FreeBank chain no longer needs a new app. When easynet starts FreeBank afresh, update the node from
the Node tab and it syncs the new chain: the app reads which chain that is from the node release itself, signed like
the rest of it. Nothing changes on mainnet.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Easynet's chain comes with the node release.** From the next FreeBank release for easynet, each one carries a
  small file naming its chain. The app reads it only after the release's signature and checksums check out, keeps a
  checked copy, and checks that copy again each time it starts. It looks for a new node release every ten minutes,
  so when one names a newer chain, the footer and the Node tab offer the update soon after it's out. The update sets the old chain's data aside once and, as before, keeps only the two newest
  set-aside copies. The wallet and the node's settings stay where they are.

- **What it refuses.** A file that doesn't check out, one that names mainnet's, beta's or regtest's chain, or one
  older than the chain in use isn't taken, and the Node tab says why. A data folder holding another network's
  FreeBank chain is never set aside for easynet: the app asks you to choose another folder under Advanced. If the
  saved copy is damaged, the node's data stays where it is until the app reads the chain from a release again.

- **If a release disagrees with itself.** If a node writes another chain than its release names, the app sets the
  data aside once, then says so on the Node tab and asks for a report from Settings › About, instead of setting the
  data aside again and again.

## Honest limits

- FreeBank v1.2.3, the current easynet release, doesn't carry the file, so until the next easynet release this version
  works as v0.7.7 does.
- If easynet's eCash chain itself starts again, not only FreeBank's, an app update is still needed.
- Tried on Linux on 22 November against a stand-in release signed with a test key, not a real release: the app took
  the new chain, offered the node update, set the old chain's data aside once and kept the wallet, and the node
  synced. A tampered saved copy was refused and nothing moved; back online, the app read the chain from the release
  again and the message cleared.
- This version hasn't run on a Mac yet; v0.7.4 has.
