# FreeBank app v0.6.11 "past block 218"

A FreeBank node that was still on v0.2.29 when easynet's block 219 came out refused that block. Block 219 is the
first one under v1.0.1's rules. The node remembers a block it refused, and it may also have banned easynet's
FreeBank peer for a day for sending it. So after the update to v1.0.1 it still stopped at 218. This version has the node check such
blocks again.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Blocks an earlier node release refused are checked again:** once for each release of FreeBank's node the app
  runs (after an update, and on this version's first start), once eCash has caught up, the app has the node check
  again every block it holds as bad. A block the newer release takes is followed as usual, and the Node tab says
  which. A block that really is bad is refused again. The peers the node had banned for sending such blocks are let
  back in. Bans set by hand stay. A node stuck at easynet's block 218 moves on by itself.
