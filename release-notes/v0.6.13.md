# FreeBank app v0.6.13 "easynet-4.1"

On easynet, the app now runs eCash's newest node (v1.2.0) and the enforcer built for eCash mainnet, the same programs
easynet itself moved to. Settings › Node & connection offers the update; your chain, wallet and coins stay as they are.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **easynet-4.1.** The eCash node and the enforcer update together, in one step: the old enforcer can't work with the
  new node. Both downloads are checked against easynet-4.1's published checksums. Nothing is synced again.

## Honest limits

- easynet-4's programs keep working on the same chain, so an app that hasn't updated yet keeps working too.
- On easynet, notes, bills, pools and deposits pause until FreeBank-easynet block 600 (FreeBank v1.0.2).
- Not yet run on a Mac.
