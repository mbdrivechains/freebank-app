# FreeBank app v0.6.2 "Start on easynet"

A new computer now starts FreeBank on easynet: FreeBank sets it all up in a few minutes, and the easynet faucet gives
test coins. Beta's demo mode, which ran without an eCash node, has ended; beta stays for full setups.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Newcomers start on easynet.** On a computer that hasn't run the app on beta, FreeBank opens on easynet, with a
  welcome that says what it is and **Let FreeBank set it up** first. **Or use eCash beta** switches to beta for someone
  who runs BitWindow there. A computer that has run the app on beta stays on beta, and its welcome screen offers
  **Switch to easynet** first.
- **Getting started on easynet.** Home has a card with the first steps: test coins from Receive, a payment, eCash and
  Deposit, the houses. "Got it" folds it.
- **Beta's demo mode has ended.** It ran FreeBank on beta without an eCash node, through FreeBank's gateway, with play
  money from the Telegram bot. On beta, blocks now come hours apart, too slow to try anything. An app still in demo mode
  goes back to setup when it updates: its beta wallet and node stay, and setup offers easynet or a full beta setup.

## Honest limits

- Borrowing from a house still happens in the Telegram bot, on beta. Houses on easynet, and a bot for them, are being
  set up.
- Not yet run on a Mac.
