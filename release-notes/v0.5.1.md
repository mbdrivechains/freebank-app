# FreeBank app v0.5.1 "Beta's own node"

On beta, FreeBank can now run eCash beta's node and enforcer itself, or use the ones on another computer near you. You
no longer need BitWindow for either.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Beta's own node.** Setup on beta offers "Let FreeBank run eCash beta's node". FreeBank downloads the node and
  enforcer (about 105 MB), checks them against the hashes in this release, and runs them. The whole chain comes to
  about 890 GB.
- **A snapshot first.** FreeBank looks for a snapshot before it starts: ours at block 967,000, else LayerTwo Labs' at
  935,000 (the one BitWindow uses). Each is named by who publishes it. With one, the node reaches beta's tip in hours:
  in our test the 9.4 GB download took an hour, loading it 10 minutes and catching up 23 minutes. Without one, it syncs
  from the start, which takes days. Either way, the node then fetches and checks the older blocks behind it, so a
  snapshot saves time, not disk space.
- **Stop and delete, at any point.** While it downloads, loads its snapshot or syncs, and afterwards in Settings, "Stop
  and delete" stops it at once and deletes its chain, and setup then offers the choices again. Setup shows the free
  space against what the chain needs, and FreeBank stops the node itself if less than 20 GB is left. The blocks can go
  on a bigger disk: FreeBank makes its own folder there and deletes only that.
- **Another computer's node.** Type its IP address or Tailscale name: FreeBank finds its eCash node and enforcer on the
  usual ports and uses them. Nothing is downloaded here, and nothing on that computer is deleted. With a login,
  FreeBank's eCash wallet adds two watch-only wallets of its own to that node, as it does with any eCash node, and
  never opens its other wallets. A login typed for one computer is forgotten when you choose another, so it is never
  sent elsewhere. FreeBank says when the link isn't Tailscale's, since nothing on it is then encrypted.
- **Obliterate** lists FreeBank's own eCash node as a line of its own, with its size: untick it to keep the chain. For a
  node on another computer, it says that nothing there is deleted.

## Honest limits

- The eCash node and enforcer are mbdrivechains' builds (the node with our 967,000 snapshot entry, proposed to eCash),
  not eCash or LayerTwo Labs releases. FreeBank checks they are the files this release names; their release notes say
  how each was built.
- Our snapshot is ours, not L2L's or eCash's. The node checks it against the hash compiled into it, which was checked
  against Bitcoin Core 31.1 run from the start.
- The whole chain needs about 890 GB, and the enforcer refuses a node that prunes old blocks.
- FreeBank stops the node for low disk space only while the app is open. With "Keep running" on and the app closed, the
  node goes on until the disk is nearly full, when it stops by itself.
- An eCash node on another computer must be set up there to let this one in (its REST and RPC, and its enforcer).
  FreeBank changes nothing else there: it reads the chain, keeps its two watch-only wallets and sends your payments.
- FreeBank's own eCash node takes RPC and REST only from this computer, so other computers can't use it as their node.
- Not yet run on a Mac.
