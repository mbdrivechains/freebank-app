# FreeBank app v0.5.0 "Networks: easynet"

FreeBank can now run on easynet as well as beta, and on easynet it sets up everything itself: no BitWindow.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Networks.** Settings › Node & connection has a Network card: switch between beta and easynet there. FreeBank
  restarts on the other one. Each network keeps its own wallet, settings and node, and the one you leave stays as it
  was. Mainnet is shown greyed out until it starts.
- **easynet, set up for you.** easynet is a small public test network on eCash's rules, with no value. On easynet,
  FreeBank downloads its eCash node and enforcer (about 105 MB), checks them against the hashes in this release, runs
  them and syncs in a few minutes. FreeBank's own easynet node comes from the FreeBank release, and its signature is
  checked as always. The welcome screen offers easynet beside the demo.
- **Your easynet node in Settings:** its block and peers, the enforcer, its ports and release, with Start and Stop, and
  Update when FreeBank has a newer release of them.
- **Ports.** FreeBank's own eCash node never takes the ports BitWindow's beta node and enforcer use. If another program
  holds one of its ports, FreeBank names that program and uses free ports instead. It never changes another program's
  settings.
- **One set of words.** An easynet wallet can take your beta wallet's recovery words ("The words of my Beta wallet"),
  opened with that wallet's passphrase. The same words then bring back both wallets. The networks share no coins.

## Honest limits

- easynet coins have no value. It is a test network.
- The eCash node and enforcer FreeBank installs on easynet are mbdrivechains' builds of eCash's node and LayerTwo
  Labs' enforcer, not releases of theirs. FreeBank checks they are the files this release names, not how they were
  built; easynet's release notes say how each was built.
- On beta, nothing changes: FreeBank still uses the eCash node and enforcer you run, for example in BitWindow.
- The eCash node FreeBank runs talks to easynet's other nodes, as any full node does. Its RPC and the enforcer
  listen on this computer only.
- The Mac build has not yet been run on a Mac with easynet.
