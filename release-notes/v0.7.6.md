If a node the app uses falls behind the network, a banner on every screen now says so: when it rejects blocks the
rest of the network accepts, or hears of no new block for hours. When an update fixes it, the banner points to the
update. The Node tab no longer says "In sync" when no block has come for two hours, and a connection that never
answered no longer counts as a peer. Old copies of a test network's chain data no longer pile up: the app keeps the
two newest and deletes the rest.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and

## What's new

- **A banner when a node falls behind.** It shows on every screen, for FreeBank's node and for the eCash node the app
  uses, for as long as the reason holds:
  - the node's own warning, such as FreeBank's "You may need to upgrade" once the rest of the network has moved on to
    blocks it rejects;
  - a node that knows of newer blocks but hasn't added any for 30 minutes;
  - a node that has had no new block for two hours, with its newest block's time and how many peers it has.

  When a node or app update is offered, the banner points to it.

- **"In sync" means blocks are coming.** The Node tab now says "No new block" when its newest block is two hours old,
  with that block's time, and never says "In sync" with no peers. A peer is counted only once it has answered.
  Before, a connection to a relay with nothing behind it counted as one, and the tab read "In sync" for hours while
  easynet was down.

- **Easynet's FreeBank v1.2.2 chain.** v0.7.5 updated the node to v1.2.2 but left the v1.2.0 chain's data where it
  was, so the node stopped with "Incorrect or no genesis block found". This version sets that data aside, and the node
  starts on its own chain.

- **Old chain data doesn't pile up.** When a test network starts again, the app sets the old chain's data aside. Now it
  keeps only the two newest of those copies, for FreeBank's node and for the eCash node it installs, and deletes the
  older ones. A folder holding a wallet or a node's settings is never deleted.

- **A payment to yourself is one row** in the eCash tab's history ("Sent … to yourself"), not a Sent and a Received.

## Honest limits

- FreeBank on easynet now runs test builds newer than any public release, and has started new chains since 19 November.
  The app installs only FreeBank's signed releases, so until the next one its FreeBank node on easynet has no one to
  sync with, and the Node tab says so. The eCash wallet on easynet works as before.
- Tried on Linux on 19 November, from a v0.7.5 install on easynet: the app set the v1.2.0 chain's data aside, deleted
  the oldest copy so two remain, left the wallet and the node's settings in place, and updated the node to v1.2.2.
  With no block for two hours, the Node tab read "No new block" with the newest block's time, and the banner showed
  on every screen five minutes later.
- This version hasn't run on a Mac yet; v0.7.4 has.
