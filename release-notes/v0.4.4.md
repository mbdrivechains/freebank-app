# FreeBank app v0.4.4 "Demo"

Try FreeBank in a few minutes, with play money and no eCash node.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Demo mode.** On a computer with no eCash beta node, the first screen now offers **Try the demo**. FreeBank
  installs its own node (v0.2.25 or newer), which catches up with the FreeBank beta chain in a few minutes: about
  seven in our tests. Instead of your own eCash node and enforcer, it asks FreeBank's read-only gateway about the eCash
  chain. The app's relay passes on only the six questions a FreeBank node asks, over TLS with the gateway's
  certificate checked.
- **Get play money** (Home › Receive, on the beta). It opens FreeBank's Telegram bot: tap Start there, and the bot
  sends a little sECX to this wallet, once per Telegram account while the day's supply lasts. It arrives within about
  half an hour. Receive then moves to a new address.
- **A first screen for newcomers.** On a computer that has never run FreeBank and has no eCash node, setup leads with
  the demo. BitWindow and your own eCash node remain the way to run FreeBank in full.
- Smaller: plainer words while setting up and protecting a new wallet.

## Honest limits

- Demo mode trusts FreeBank's gateway for what happened on the eCash chain; a full setup checks that with its own
  eCash node and enforcer. The gateway sees your computer's IP address and the questions your node asks.
- While the gateway is down, a demo node stops following the chain, and catches up when it answers again.
- In demo mode there is no eCash tab, no deposits or withdrawals, and no bidding for blocks.
- A demo node runs only while the app is open: Keep running, the phone's background part and starting at login stay
  off in demo mode, and stay off after you leave it until you turn them on again.
- To leave demo mode (Settings › Node & connection), your own eCash node and enforcer must be answering.
- Play money is beta sECX and has no value. Getting it needs a Telegram account.
