# FreeBank app v0.6.3 "Beta from 965,000"

A computer that runs eCash beta's node itself now starts it from Bitcoin Core's own snapshot at block 965,000, Ava
Chow's file, in place of ours at 967,000; else from her file at 935,000, in place of LayerTwo Labs' copy of it, which
never loaded on beta.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **Beta's node starts from Bitcoin Core's 965,000 snapshot.** The eCash node setup installs on beta is now
  mbdrivechains' `betanet-965000-1`: eCash's betanet node plus Bitcoin Core's own entry for block 965,000, unchanged. It
  starts from Ava Chow's snapshot of that block (9.5 GB), else hers at 935,000 (9.4 GB), else a full sync. Our snapshot
  at 967,000, and the node made for it, retire.
- **Snapshots made for Bitcoin load on beta.** Ava Chow's files say Bitcoin in 4 bytes of their header, and beta's node
  refuses a file that doesn't name beta. FreeBank now writes beta's 4 bytes there once the download is whole, and
  changes nothing else. Then it checks the file's hash, and the node checks its UTXO hash against the one compiled into
  it.
- **The 935,000 choice is now Ava Chow's file.** LayerTwo Labs' copy, offered since v0.5.1, is the same file with
  alphanet's 4 bytes, so beta's node never loaded it.
- **Settings follows an update of the eCash node:** Update and Continue show the stage it is at and, if it stops,
  why. Before, a stopped update there said nothing.
- **After Stop and delete,** setup picks the first snapshot that answers again, not a full sync.
- **An install still waiting on the 967,000 snapshot** carries on with Ava Chow's 965,000 once its node is updated
  (Settings, Node & connection), and the old part-file is deleted.

## Honest limits

- Ava Chow's server sent about 2.5 MB/s in our test, so the download takes about an hour.
- Both snapshots are on her server: if it doesn't answer, the node syncs from the start.
- A beta node that started from the 967,000 snapshot, and is still checking the history behind it, can't move to the
  new node, which has no entry for that block. Settings says so: Stop and delete, then Install, starts afresh from
  965,000.
- Not yet run on a Mac.
