# FreeBank app v0.6.10 "easynet deposits"

FreeBank's node v1.0.1 credits every deposit onto FreeBank under eCash's new enforcer. Since easynet's restart on
29 October only the first deposit had been credited; v1.0.1 credits the ones left waiting in its first block. On
easynet that is a change of rules: a node older than v1.0.1 stops at that block. This version installs v1.0.1 there.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **easynet takes FreeBank v1.0.1:** on easynet the Node tab offers FreeBank's node v1.0.1; press **Update**. It
  keeps its data folder and wallets, and needs no new sync. Deposits left waiting since the restart are credited
  in v1.0.1's first block on easynet, which only a v1.0.1 node accepts. FreeBank's v1.x releases are still marked as pre-releases until mainnet is switched on;
  easynet runs them first, so the app takes them there (and only there), with the same signature check as before.
