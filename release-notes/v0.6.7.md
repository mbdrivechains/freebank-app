# FreeBank app v0.6.7 "easynet-3.2"

The app's own easynet node moves to **easynet-3.2**. From block 4032 (expected around 23:00 UTC on Wednesday 28
October), easynet's difficulty rule becomes eCash mainnet's, and a node on easynet-3.1 stops at block 4031.

## Download

From the [releases page](https://github.com/mbdrivechains/freebank-app/releases/latest): the `.deb` for Ubuntu and
Debian, the `.dmg` for a Mac, the `.AppImage` for other Linux. v0.2.4 and later offer this update themselves.

## What's new

- **easynet's node is easynet-3.2** (github.com/mbdrivechains/bitcoin): the same chain, genesis and ports as
  easynet-3.1, with one rule changed from block 4032. Up to block 4031 each block's difficulty is set as now (ASERT);
  block 4032 has a fixed one; after it the difficulty changes only once every 288 blocks, as on eCash mainnet.
- **To update an easynet node the app runs:** once the app is on v0.6.7, it opens on its setup screen, which says that
  FreeBank has a newer easynet node: press **Update to easynet-3.2** (also in Settings › Node & connection). The new node
  keeps the blocks the old one had, so FreeBank is back in a minute or two. Until then FreeBank on easynet doesn't
  start.
- **The setup screen offers Update itself** when FreeBank has a newer eCash node than the one installed. Before, it
  offered Start it, which did nothing, and the reason was at the foot of the screen.
- The enforcer is unchanged (easynet-3.1's). Beta is unchanged.

## Honest limits

- The update is a press of Update in Settings, not automatic.
- Not yet run on a Mac.
